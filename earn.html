Provider playbook

Put your GPUs to work on OctaSpace

List your hardware, set your own prices, get paid in OCTA per minute — and let idle mining cover the gaps. Here's the full path from zero to earning.

What you need

🖥️

Hardware

Any x86-64 or ARM machine running Linux (Ubuntu LTS / Debian recommended; Windows node support in beta). Minimum: 1 CPU, 1GB RAM, 10GB disk. For AI/ML workloads: NVIDIA or AMD GPUs on a high-bandwidth PCIe slot, plus ample storage.

🔒

Staking: optional, not required

Running a node takes no OCTA stake — you earn from rentals and idle mining with just the software running. Staking is an optional extra: lock 100,000 OCTA as collateral (currently …) and keep node reliability above 75% over 30 days to earn staking rewards on top. Across the whole network, … OCTA is currently staked (live via api.octa.computer). Figures per the OctaSpace whitepaper — confirm the current requirements in the official docs before buying OCTA.

🌐

Connectivity

Stable internet with solid upload — the network benchmarks your up/down speed, disk write speed, and GPU performance so renters can pick the right box for the job.

Setup in five steps

Install the node software

Grab orc, the OctaSpace node software, from the official GitHub org:

github.com/octaspace/orc

Follow the repo README for your distro. Docker images are published under octaspace on Docker Hub.

Optional: stake for rewards

No stake is needed to operate a node — this step is purely for extra yield. Get OCTA (bridge from Ethereum/BSC or buy on a listed venue), lock the 100,000 OCTA collateral (whitepaper figure — verify current), and link your wallet to your node. Staking rewards flow to that wallet address.

Configure services

Choose what your node sells: GPU compute, VPN exit, storage, rendering. Set your own per-minute prices — check the comparison page to position against Vast.ai rates.

Enable idle mining

Add an Idle Job (e.g. XMR via xmrig) so the node mines automatically when no rental is active and yields instantly when one starts. Unrented ≠ unpaid.

Stay reliable

Uptime is your reputation score — it's on-chain and renters see it. If you stake, hold 75%+ over 30 days (per the whitepaper) to keep your staking rewards; dip below and rewards pause.

Provider tips

🎯

Price against Vast.ai, not AWS

Renters cross-shop you against Vast.ai spot ($0.15–0.29/hr for a 4090). Undercut slightly on price or win on reliability score and included services.

📦

Sell the whole box

A GPU node that also offers VPN exit and storage earns three ways from one machine. Enable every service your hardware qualifies for.

🔋

Idle mining is the edge

Vast.ai hosts earn zero when idle. Your node never does. Size your idle-mining config for your power rate so the floor stays profitable.
