Your rigs, in your pocket

GPU temps, node control, rental prices and idle jobs for your own OctaSpace rigs — live from the free, open-source octa-host-agent running on each rig. This page talks to your rigs directly; no account, no middleman, nothing leaves your network except calls to your own hardware.

⏻ Power

Shutdown is final until someone powers the rig on locally, another always-on machine on the LAN sends it a Wake-on-LAN packet, or a smart plug restores power (with "power on after AC loss" set in BIOS). Software alone cannot switch a powered-off machine back on.

Sent by the selected rig's agent — so the selected rig must be ON (use any always-on machine on the same LAN). The target needs WoL enabled in BIOS/NIC settings and wired power.

💲 Rental price

The agent saves this target on the rig. If you added your OctaSpace API key to the agent's config (on the rig — never in this page), the agent also applies it to your listing through the official OctaSpace API (PATCH /nodes/{id}/prices, USD cents). Without a key on the agent, the target is saved on the rig only and you apply it in your OctaSpace service listing ↗. Either way, the agent reports which one happened.

🌙 Idle job

Automatic start/stop needs rental detection, which needs your OctaSpace API key on the agent; otherwise start/stop manually here. "Pause" is honest about its limit: the OctaSpace API has no node pause switch, so the agent stores the preference and reports it — it does not enforce it. Idle jobs are created in your OctaSpace account; the official API exposes their status, not creation.

Get the agent

Free, open source, one Python file — no dependencies

Install on the rig

On each Linux rig (Windows notes in the README):

git clone https://github.com/Kshot3000/octa-host-agent

then

python3 agent.py

Python 3.8+ only — GPU data comes from nvidia-smi. A systemd unit is included for always-on use.

Copy the token

The agent prints a token on startup and stores its config at ~/.config/octa-host-agent/config.json. That token is the only key to the agent — treat it like a password.

Connect above

Paste the rig's LAN address (e.g. http://192.168.1.50:8787) and token into the connect form. Away from home, reach the same address over Tailscale/WireGuard — never port-forward the agent to the open internet.

Optional: OctaSpace API key

Add octa_api_key to the agent config on the rig to unlock: price changes applied to your live listing via the official API, your node list + API reboot here, and automatic idle-job start/stop. The key never leaves the rig except to api.octa.space.

On the go

Your phone talks to your rigs the same way this page does — over your LAN at home, or over your VPN (Tailscale/WireGuard) anywhere else. There is no cloud relay and no native App Store / Play Store app; the PWA is the mobile app.
