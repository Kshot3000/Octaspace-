Contribute upstream

Found a bug? Fix it where everyone benefits.

  • We're auditing every repo in the octaspace org for real bugs — broken docs, stale dependencies, dead links, code issues — and opening pull requests with fixes.
  • All PRs go out from Kshot3000, tagged for the OctaSpace team to review. Helping the network win means making its software better, not just talking about it.
  • Want to help? Fork any repo above, fix something real, and tag @kshot9000 so we can amplify it.
